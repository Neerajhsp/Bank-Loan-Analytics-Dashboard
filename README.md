# 🏦 Bank Loan Analytics Dashboard

> An interactive Power BI dashboard designed to analyze bank lending performance, loan portfolio health, repayment behavior, and borrower risk indicators through data-driven insights.

---

## 📊 Project Overview

The **Bank Loan Portfolio Analysis & Performance Dashboard** is a business intelligence project built using **Microsoft Power BI** to provide a comprehensive view of lending activities and portfolio performance.

The dashboard transforms loan data into meaningful business insights by tracking key financial and operational metrics, analyzing Good vs Bad Loans, monitoring repayment behavior, and identifying trends across time, geography, loan purpose, loan term, and borrower characteristics.

The goal is to help stakeholders understand the overall health of the loan portfolio and make informed, data-driven lending decisions.

---

## 🎯 Business Objectives

- Analyze overall loan portfolio performance.
- Monitor lending and repayment activities.
- Track Good Loans vs Bad Loans.
- Evaluate funded amounts and repayments.
- Monitor average interest rate and borrower DTI.
- Identify monthly loan application trends.
- Analyze loan performance across regions.
- Understand loan purpose and loan-term distribution.
- Provide interactive filtering for deeper analysis.
- Support data-driven lending and portfolio management decisions.

---

## 📌 Key KPIs

The dashboard tracks important lending KPIs including:

| KPI | Purpose |
|---|---|
| 📝 Total Loan Applications | Measures total loan applications received |
| 💰 Total Funded Amount | Tracks the total amount disbursed as loans |
| 💵 Total Amount Received | Measures repayments received from borrowers |
| 📈 Average Interest Rate | Evaluates the average interest rate across loans |
| 📊 Average DTI | Helps assess the financial profile of borrowers |

## 🔍 Key Business Analysis

### Good vs Bad Loans

The dashboard separates loan applications into **Good Loans and Bad Loans** to help understand portfolio quality and repayment performance.

### Loan Status Analysis

Loan applications, funded amounts, repayments, interest rates, and DTI are analyzed across different loan statuses to identify performance patterns.

### Time-Based Analysis

Monthly loan application trends help identify changes in lending activity over time.

### Regional Analysis

Regional visualization provides a geographical view of lending activity and helps identify differences across locations.

### Loan Purpose Analysis

Loan purposes are analyzed to understand where borrowers are utilizing loan facilities and which purposes contribute to the portfolio.

### Borrower Profile Analysis

Home ownership, loan grade, interest rate, and DTI provide additional insights into borrower characteristics and portfolio quality.
